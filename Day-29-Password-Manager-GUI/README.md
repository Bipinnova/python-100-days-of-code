# 🔐 Day 29 - Password Manager GUI

> **Part of my #100DaysOfCode Journey**

For Day 29 of my **#100DaysOfCode** challenge, I built a **Password Manager GUI** using **Python Tkinter**.

The application allows users to generate strong random passwords, copy them directly to the clipboard, validate user input, and securely store website credentials in a local file. While developing this project, I focused on improving the user experience through dialog boxes, input validation, and a clean graphical interface.
