# 🔄 Day 27 - Professional Unit Converter

> **Part of my #100DaysOfCode Journey**

For Day 27 of my **#100DaysOfCode** challenge, I transformed the basic Miles-to-Kilometers converter into a **Professional Unit Converter** using **Python Tkinter**.

Instead of supporting a single conversion, the application now provides multiple unit conversions through an intuitive graphical interface. I also focused on improving the application's usability by adding input validation, conversion history, keyboard shortcuts, and a modular project structure.

# 💡 Engineering Takeaway

Rather than extending the original project in a single file, I separated the application's user interface, business logic, and configuration into dedicated modules. This made the project easier to understand, maintain, and extend while also improving the overall user experience through validation, reusable conversion logic, and additional features.
