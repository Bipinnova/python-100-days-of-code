# 🍅 Day 28 - Pomodoro Timer

> **Part of my #100DaysOfCode Journey**

For Day 28 of my **#100DaysOfCode** challenge, I built a **Pomodoro Timer** using **Python Tkinter**.

The application follows the Pomodoro productivity technique by alternating between work sessions, short breaks, and long breaks. It automatically manages session transitions, displays a countdown timer, and tracks completed work sessions with visual check marks.
