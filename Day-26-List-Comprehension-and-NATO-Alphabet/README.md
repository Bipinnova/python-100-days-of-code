# 🔤 Day 26 - NATO Phonetic Alphabet Generator

> **Part of my #100DaysOfCode Journey**

For Day 26 of my **#100DaysOfCode** challenge, I built a **NATO Phonetic Alphabet Generator** using **Python** and **Pandas**.

The application reads the NATO phonetic alphabet from a CSV file, creates a dictionary using dictionary comprehension, accepts a word from the user, and converts each letter into its corresponding NATO phonetic code.

Along the way, I revisited one of Python's most powerful features—**List Comprehensions** and **Dictionary Comprehensions**—to write cleaner and more expressive code.
